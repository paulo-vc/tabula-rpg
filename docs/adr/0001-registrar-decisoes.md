# 0001 — Registrar decisões de arquitetura

- **Status:** Aceita
- **Data:** 2026-10-04

## Contexto

O projeto será público e evolui em fases. Decisões como "por que não Supabase?" ou "por que relay?" tendem a ser rediscutidas se o motivo se perder.

## Decisão

Registrar toda decisão estrutural como ADR curta em `docs/adr/`, no formato: Contexto → Decisão → Alternativas → Consequências.

## Consequências

- Novos colaboradores entendem o porquê, não só o quê.
- Mudar de ideia é permitido, mas explícito: uma nova ADR substitui a antiga.
